# Multimorbidity Data 2

Simulated data containing information for 60 chronic diseases on 2699
subjects.

## Usage

``` r
datamm2
```

## Format

A data frame with 2,699 rows and 65 columns:

- subject_id:

  Subject id.

- cov1, cov2,cov3:

  Generic binary covariate information

- age:

  Subject's age at disease assessment

- dis\_...:

  binary variables containing information regarding 59 chronic disease
  diagnoses.
