# Multimorbidity Data

Simulated data containing information for 59 chronic diseases on 2900
subjects.

## Usage

``` r
mmdata
```

## Format

A data frame with 2,900 rows and 60 columns:

- id:

  Subject id.

- dis1, dis2,...,dis59:

  binary variables containing information regarding disease diagnoses.
